# 3CC3

SMRTTECH 3CC3 - L04

Includes a folder for several labs where we learned how to use different sensors, actuators, controllers, and backend/frontend softwares for IoT networks.

Includes a final group lab project: Crossing Gate System, an IoT network to safely monitor and regulate a railroad intersection with a civilian road. Final project of McMaster BTech SMRTTECH 3CC3 course. Read the attached proposal in hte Project Management folder for more infomration. Video link: https://youtu.be/cwHOEeOB2YQ

In this course, I also had to research a sensor and present it in a video format at the end of the semester. I chose industrial computer vision cameras. Video link: https://youtu.be/m290MuLuXB0
