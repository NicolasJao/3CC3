# Cloud Computing and Internet of Things

SMRTTECH 3CC3 - L04

Includes a folder for several labs where we learned how to use different sensors, actuators, controllers, and backend/frontend softwares for IoT networks.

Includes a final group lab project: Crossing Gate System, an IoT network to safely monitor and regulate a railroad intersection with a civilian road. Final project of McMaster BTech SMRTTECH 3CC3 course. Read the attached proposal in the Project Management folder for more infomration. Video link: https://www.youtube.com/watch?v=Kfs-jLGk4gE

In this course, I also had to research a sensor and present it in an entertaining video format at the end of the semester. I chose industrial computer vision cameras and presented it as a parody of the YT channel AsapSCIENCE. Video link: https://www.youtube.com/watch?v=eLxUBFdocPw
